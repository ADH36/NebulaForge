# Official Unreal Engine API Audit

This file records the API checks behind roadmap decisions for optional UE5 import and character integrations. It is intentionally short and updated when a capability is implemented or reclassified.

| Capability | Epic API/documentation evidence | Current bridge status |
| --- | --- | --- |
| Generic Interchange import | [`UInterchangePipelineBase`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/InterchangeCore/UInterchangePipelineBase), [Interchange import guide](https://dev.epicgames.com/documentation/en-us/unreal-engine/importing-assets-using-interchange-in-unreal-engine) | `manage_asset.import_with_interchange` validates supported extensions and uses the deferred editor-safe importer. Pipeline-stack authoring remains open because the bridge currently calls `UAutomatedAssetImportData`/`ImportAssetsAutomated` and does not own a project-specific pipeline object. |
| Nanite asset configuration | [`UStaticMesh` API](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/Engine/UStaticMesh), Nanite editor tooling | `manage_asset.configure_nanite_import` delegates to the asset-scoped Nanite rebuild path; global Nanite CVars remain under performance controls. |
| Skeletal-mesh LOD | [`USkeletalMeshComponent`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/USkeletalMeshComponent), [`USkinnedMeshComponent`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/Components/USkinnedMeshComponent) | MetaHuman/avatar/groom LOD façades use validated reflected component properties plus `ForcedLodModel`/`MinLod`; plugin-specific bias fields remain project-defined. |
| Actor tags | [`AActor`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor) and [`UGameplayStatics::GetAllActorsWithTag`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/UGameplayStatics/GetAllActorsWithTag) | `control_actor.get_actor_tags`/`set_actor_tags` read and persist the actor `Tags` array; registered hierarchical Gameplay Tags remain separate actions. |
| Component tags | [`AActor::GetComponentsByTag`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor/GetComponentsByTag) | `control_actor.get_components_by_tag` returns matching component identity metadata without conflating component tags with actor or Gameplay Tags. |
| Component tag authoring | [`UActorComponent`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/UActorComponent) | `control_actor.set_component_tags` replaces the resolved component's `ComponentTags` array and marks the owning editor package dirty. |
| Component tag readback | [`UActorComponent`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/UActorComponent) | `control_actor.get_component_tags` returns the exact `ComponentTags` array for a resolved component. |
| Incremental component tag edits | [`UActorComponent`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/UActorComponent) | `control_actor.add_component_tag`/`remove_component_tag` perform idempotent edits and report prior/current presence. |
| Actor folder organization | [`AActor::GetFolderPath`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor) and [`AActor::SetFolderPath`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/GameFramework/Actor/SetFolderPath) | `control_actor.get_actor_folder_path`/`set_actor_folder_path` expose development-build actor folders and persist editor changes. |
| Recursive actor folders | [`AActor::SetFolderPath_Recursively`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/GameFramework/Actor/SetFolderPath_Recursively) | `control_actor.set_actor_folder_path_recursive` assigns a folder to an actor and its attached children. |
| Actor labels | [`AActor`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor) | `control_actor.get_actor_label`/`set_actor_label` expose editor actor labels and persist label changes. |
| Actor tick settings | [`AActor`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor) and [`AActor::SetActorTickInterval`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor/SetActorTickInterval) | `control_actor.get_actor_tick`/`set_actor_tick` expose tick enablement and non-negative primary tick intervals. |
| Actor lifespan | [`AActor::SetLifeSpan`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/GameFramework/Actor/SetLifeSpan) and [`AActor`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor) | `control_actor.get_actor_lifespan`/`set_actor_lifespan` expose the remaining actor lifetime; zero clears the destruction timer. |
| Actor ownership | [`AActor::GetOwner`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/GameFramework/Actor/GetOwner) | `control_actor.get_actor_owner` reports whether an owner exists and returns owner label, object name, and path metadata. |
| Actor default labels | [`AActor`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor) | `control_actor.get_actor_default_label` returns the default editor label without the numeric instance suffix. |
| Actor velocity | [`AActor`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor) | `control_actor.get_actor_velocity` returns root-component or movement-component velocity in cm/s plus scalar speed. |
| Attached parent actor | [`AActor::GetAttachParentActor`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/GameFramework/Actor/GetAttachParentActor) | `control_actor.get_attach_parent_actor` reports the actor found by walking the root-component attachment chain. |
| Temporary editor visibility | [`AActor`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/AActor) | `control_actor.get_actor_editor_visibility`/`set_actor_editor_visibility` use the session-only editor visibility APIs without conflating them with runtime hidden state. |
| Performance feature toggles | [Epic Scalability Reference](https://dev.epicgames.com/documentation/unreal-engine/scalability-reference-for-unreal-engine) and [Console Variables C++](https://dev.epicgames.com/documentation/en-us/unreal-engine/console-variables-cplusplus) | `system_control.enable_disable_features_for_performance` applies only allowlisted UE scalability CVars and reports `NOT_SUPPORTED` when a selected CVar is unavailable. |
| Alembic import modes | [`EAlembicImportType`](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Plugins/AlembicLibrary/EAlembicImportType), [Alembic importer guide](https://dev.epicgames.com/documentation/unreal-engine/alembic-file-importer-in-unreal-engine) | `.abc` import is exposed through the deferred importer when the Alembic translator is installed. Geometry/groom/animation option authoring remains gated until the project exposes the optional importer settings classes. |
| URL-backed Interchange source data | [InterchangeCore API index](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/InterchangeCore) | `load_avatar_from_url` remains open: Epic's current source-data documentation does not provide a stable URL-to-import path for this bridge, so callers must download to a project-controlled local path before using `load_avatar_from_glb`. |

Native Unreal compilation is still environment-dependent; TypeScript build/type-check, unit tests, parity audit, and whitespace checks are run for each increment.

## Current roadmap baseline

At the latest audit, `docs/Roadmap.md` contains 1,118 checked entries and 331 unchecked entries (audited 2026-09-03). The unchecked set is concentrated in integrations whose public API is supplied by optional plugins or external services: MetaHuman DNA/Rig Logic, Mutable, Fab/Megascans, USD authoring, Substance, Houdini, SpeedTree, Datasmith, Wwise, FMOD, Live Link providers, nDisplay, Composure/OCIO, Remote Control, DMX/OSC/MIDI, XR platforms, EOS/Steam, and third-party character/voice services. These remain open until the project supplies the corresponding plugin modules and version-specific public classes/settings.
